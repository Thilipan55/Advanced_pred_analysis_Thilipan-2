# Medical Diagnosis Support using Decision Trees

## Thilipan - 23MID0272



A machine learning project that classifies breast tumors as \*\*Malignant\*\* or \*\*Benign\*\* using the Breast Cancer Wisconsin (Diagnostic) dataset.



## Features

- Data Exploration \& EDA

- Decision Tree Classification

- Pre-Pruned Decision Tree

- 5-Fold Cross Validation

- Model Evaluation

- Feature Importance \& Tree Visualization



## Technologies

- Python

- Pandas

- NumPy

- Matplotlib

- Seaborn

- Scikit-learn
